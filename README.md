# ITTs - Ban demo

Day la ban demo cong khai cua du an ITTs. Du lieu chi la du lieu mau,
moi thao tac duoc luu tren trinh duyet cua ban.

## Cach xem dong bo hai chieu

- Mo hai cua so tren CUNG MOT MAY (vi du: mot cua so Cong nhan vien,
  mot cua so Trang hoc vien). Thao tac ben nay, ben kia thay ngay.
- Moi may la mot bo du lieu rieng - khong dong bo giua cac may khac nhau.
- Bam nut Reset du lieu demo o man cong de dua tat ca ve nguyen ban.

## Cac trang

- `index.html` - trang bia, chon cong.
- `ITTs_WebApp_v5_demo.html` - cong nhan vien.
- `ITTs_TrangHocVien_demo.html` - trang hoc vien.
- `ITTs_data.js` - du lieu demo, app tu doc file nay khi chay.
